# Azure Views
WIP 1.4.5 TML mod that aims to overhaul Terraria's sky with a number of highly customizable visuals changes.

## Planned Features
    - [ ] 3D starbox.
    - [ ] Shooting stars.
    - [ ] Unique star visual styles.
    - [ ] Meteor changes.
    - [ ] Shimmer visuals.
    - [ ] Custom HD models for each moon style.
    - [ ] Certain atmospheric phenomena, (e.g. 22° halo/Sun dogs.)
    - [ ] Wind particles.
    - [ ] Rain particles.
    - [ ] Customizable 'atmosphere' effect.
    - [ ] Rainbows.
    - [ ] Aurora borealis.
    - [ ] Darker night sky.
    - [ ] Alternate cloud lighting visual.
    - [ ] Lunar event backgrounds.
    - [ ] Supernovae.
